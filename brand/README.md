# PlanSphere — brand assets

**Plan Infinity and Travel Beyond the World.**

| File | Use |
| --- | --- |
| `plansphere-mark.svg` | Primary mark. Avatars, app chrome, anywhere the name is already present. |
| `plansphere-lockup-horizontal.svg` | Default lockup. Site header, email signature, decks. |
| `plansphere-lockup-stacked.svg` | Centred lockup with slogan. Splash screens, print, merch. |
| `plansphere-mono-ink.svg` | Single colour on light grounds. Fax-grade reproduction, embroidery, stamps. |
| `plansphere-mono-reverse.svg` | Single colour on dark grounds. |
| `plansphere-appicon.svg` | 512×512 app tile, night ground baked in. |
| `plansphere-favicon.svg` | 24px and below. Grid lines removed, strokes thickened. |
| `identity.html` | The full identity sheet — construction, palette, type, misuse. |

## Colour

    Abyss     #051526   night grounds, app tile
    Deep Sea  #0F3D63   headings on light, orbit shadow side
    Lagoon    #1FA9CE   primary brand, links, active state
    Aurora    #7FE9D8   route highlight, data viz, success
    Sunset    #FF8A47   the node — accent only, never more than 5% of a surface
    Cirrus    #EFF3F6   light ground
    Ink       #071A2F   body text

## Type

    Archivo         wordmark, headings          500 / 600 / 700
    Spline Sans     body, UI                    400 / 500 / 600
    IBM Plex Mono   times, codes, coordinates   400 / 500

## Notes

- Text in these SVGs is live `<text>`, not outlines, so it needs Archivo and IBM Plex Mono
  installed to render correctly. Convert to outlines before sending files to a printer.
- Clear space on all sides equals 25% of the mark's height. Nothing enters it.
- Minimum sizes: mark 20px, horizontal lockup 96px wide, stacked lockup 120px wide.
- The node is the only warm colour in the system. Do not recolour it, and do not add a second one.
